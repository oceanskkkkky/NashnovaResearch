## 关键坑

- `scripts/setup_fin.py` 在非 venv 下会自动加 `--user`，把包装到
  `AppData\Roaming\Python\Python313`，既被沙箱拦截又违反隔离规则。
  **必须用 venv 的 python 运行**（`sys.prefix != sys.base_prefix` 时不加 `--user`）。
- venv 的 Scripts 不在 PATH，裸 `nashnova` 不会命中，需用完整路径或先加 PATH。
- CLI stdout 在 Windows 控制台会因 GBK 显示乱码，但 evidence JSON 是权威数据源，数据正确。
