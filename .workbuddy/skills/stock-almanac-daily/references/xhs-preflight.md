# 小红书发布合规微调（生成阶段自审）

适用范围：`format=mobile` 或 `format=both` 时的移动端HTML与小红书笔记文案 `.md`。这两件产物默认面向小红书发布，必须在生成阶段按本规则微调；桌面端研报不受本文件约束，保留完整点位。

本规则来自「小红书内容预审」skill 对金融内容的复核结论（2026-08-23 首次应用），核心判断：**个股名称 + 精确买卖点位是最典型的"荐股"形态，是小红书金融内容治理的首要风险；板块逻辑、资金面数据与条件化研究表述的风险显著更低。** 发布者无证券投资咨询资质时尤其如此。

## 1. 个股点位弱化（核心规则）

- 移动端HTML与小红书文案中，**不出现精确的个股买入/止盈/失效价格数字**（如"33.0—34.2元""跌破29.7"）。
- 改用技术形态与条件描述表达同一判断：
  - "买入观察区间 33.0—34.2元" → "回踩20日线附近企稳再考虑"；
  - "收盘跌破32.8减半" → "收盘跌破20日线减半"；
  - "失效位29.7" → "跌破60日线视为趋势结构破坏、逻辑失效"。
- 个股名称、条件式结论（逢回调观察/条件式参与/持有观察/回避）、确认条件与失效逻辑**必须保留**——合规微调只去掉精确数字，不删除风险边界；失效逻辑缺失反而增加误导风险。
- 指数点位、成交额、估值分位等市场级数据不受此条约束，正常展示。

## 2. 免责声明可见化

- 移动端HTML必须在**正文可见位置**（行情摘要栏或页脚）固定一行"仅供研究参考，不构成投资建议"；不得只放在默认折叠的 `<details>` 内（截屏发布时折叠区不可见，声明失效）。
- 小红书笔记文案末段保留一行免责声明。

## 3. 绝对化与指令性措辞

- 在原有禁用词（必涨/稳赚/抄底/必中/最佳买点/保证收益/明日一定）之外，补充：
  - "最强/第一/唯一/最佳"等绝对断言改为带口径的数据陈述：如"全市场最强主线" → "近20日涨幅居全市场前列（+33.7%）"。
  - 禁止"跟着买/上车/抄作业/直接干/带你赚钱"等指令性或服务暗示话术。
  - 不出现未经校准的胜率、收益预期。

## 4. 导流与互动红线

- 不含微信号、二维码、外链、"看主页/私信我"等站外承接话术。
- 不含"点赞收藏领取/评论1/扣1"等利益交换式诱导互动。
- 品牌与数据来源（WeStock/hithink-finance同花顺）作为归因说明保留，不构成导流。

## 5. "老黄历"包装边界

- 小红书移动端封面统一使用“行情老黄历”，不使用“股市老黄历”；“今日宜/忌”仅作为栏目导航，不得用天干地支、五行、生肖、卦象或吉时推演行情。
- 封面保留“标题仅为栏目包装，正文为数据研究”和“仅供研究参考，不构成投资建议”两行可见声明，降低玄学预测或误导性标题风险。

## 6. 笔记文案格式与标签

- 小红书正文编辑器不渲染Markdown语法。文案文件应同时提供便于手工复制的纯文本格式：将独立一行的 `**分节标题**` 转为 `【分节标题】`，将 `- 条目` 转为 `• 条目`，避免用户手工粘贴后直接显示星号或短横线。
- Markdown一级标题仅作为标题字段，不重复写入正文；话题标签统一合并到正文末尾。
- 话题标签使用中性研究词：#A股 #财经 #股票复盘 #每日复盘 #理财 观察等；不用"荐股""带买""牛股""致富代码"类标签。

## 7. 生成后自检（运行 validate 前）

- [ ] 移动端HTML与笔记md中无精确个股买卖价位
- [ ] 可见位置有免责声明一行
- [ ] 无绝对化断言、无收益承诺、无指令性买卖话术
- [ ] 无导流与诱导互动内容
- [ ] 标签中性；确认条件与失效逻辑未因微调丢失

用户明确要求正式复核时，调用「小红书内容预审」skill 对产物做预审：结论为🟡时按其建议修正后重跑校验；🟢时保持原文，不为优化而改写。

## 8. 发布操作边界（强制：仅准备材料，平台操作完全手动）

- 自动化能力仅可用于**本地材料制作**：生成与校验移动端HTML、生成小红书笔记文案 `.md`、渲染轮播图片、检查图片尺寸与顺序、列出材料路径。允许本地渲染图片，但不得访问小红书平台。
- **禁止一切小红书网页与客户端自动化**：不得打开或访问小红书创作中心，不得读取或复用平台登录态，不得扫码/登录，不得切换发布页签，不得上传图片，不得填写、粘贴或注入标题/正文/话题，不得保存平台草稿或发布前截图，不得定位、点击或触发“发布”“确认发布”“确定”等控件。
- 禁止使用浏览器自动化、坐标点击、DOM选择器、JavaScript注入、自定义组件、CDP、RPA、系统级GUI自动化或其他技术绕过上述边界。
- 即使用户明确要求“直接发布”“帮我填充”或“打开到待发布页”，也只交付本地材料与以下手动步骤：
  1. 用户自行打开小红书创作服务平台并登录；
  2. 用户手动选择“发布笔记/上传图文”；
  3. 用户按文件名编号顺序上传 `<日期>-xhs-images/` 中的图片；
  4. 用户从 `<日期>-xiaohongshu-note.md` 复制标题、正文和话题标签并粘贴；
  5. 用户人工复核封面、图片顺序、标题、正文、话题、免责声明和平台预览；
  6. 用户本人手动点击发布。
- 交付结果只能表述为“材料已准备完成”，不得表述为“已填充”“待发布页已就绪”或“发布成功”。
