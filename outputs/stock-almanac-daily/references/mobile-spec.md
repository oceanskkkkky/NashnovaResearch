# 移动端（小红书风）A股选股日报规范

当 `format=mobile` 或 `format=both` 时适用。移动端产物有两件：

1. `YYYY-MM-DD-stock-almanac-mobile.html`：竖屏单文件HTML，适合手机阅读和整页截屏发小红书图片。
2. `YYYY-MM-DD-xiaohongshu-note.md`：小红书笔记文案（标题+正文+话题标签），是发布的实际文字载体。

评分、过滤、证据和合规规则与桌面端完全一致，只改变排版与文案密度。同一份分析生成两种产物时，数据必须来自同一次取数，不得为移动端重新取数。

## 移动端HTML布局

以 `../assets/report-shell-mobile.html` 为结构起点：

- 单列卡片流，内容最大宽度 `460px` 居中，最小字号15px，行高1.7；不允许横向滚动。
- 不使用桌面端 `min-width:1268px`、双栏、宽表格；表格一律改为竖排键值行（一行一字段）。
- 仍是无JS、无外部资源的静态单文件；用户输入必须HTML转义。
- 允许有限度的移动端视觉强化：大色块结论条、圆角卡片、醒目标签；禁止渐变堆砌、闪烁动画。
- 保留纸墨体系的墨色、朱砂、金色令牌（`--m-ink:#18332d`、`--m-red:#a83e32`、`--m-gold:#b98532`），红涨绿跌不变，涨跌必须同时带正负号和文字。

## 栏目与顺序

栏目id与桌面端一致，顺序不变：`cover` → `executive-summary`（显示标题"行情摘要"）→ `macro` → `market` → `sectors` → `picks` → `watchlist`（可选）→ `risks` → `methodology`（折叠）。

证据区不进入产物：证据台账在分析过程中维护并存为同目录 `YYYY-MM-DD-evidence.md`，产物HTML不出现 `<details id="evidence">` 和 `[E01]` 编号。

- `cover`：日期、市场状态大字结论、一行宜/忌。一屏内读完。
- `executive-summary`：显示标题固定为"行情摘要"，3—5行短句，每行一个结论（市场状态、仓位、首选方向、首选股、最大风险）。若入选板块触发严重拥挤或拥挤加速，必须进入最大风险行。
- `macro`：压缩为最多2条重点新闻，每条3行以内：事件 → A股传导 → 跟踪点。
- `market`：三大指数各一行（点位+涨跌幅+状态），加最多2条操作含义。
- `sectors`：每个板块一张卡，4行以内：为什么现在；正交资金残差是否确认及量价背离；拥挤度等级/5日变化/扣分；催化与最大风险。正文不展示回归公式，完整分项留在证据台账。
- `picks`：每只股票一张大卡，固定顺序：一句话逻辑 → 3条关键事实 → 当前建议 → 观察与确认条件 → 止盈/减仓触发 → 失效条件 → 催化与风险。个股点位按 `xhs-preflight.md` 弱化：不写精确价位，用"回踩20日线企稳""收盘跌破MA60失效"等形态描述；确认条件与失效逻辑不得省略。
- `risks`：最多4条，每条一行。
- 免责声明双位置：可见正文（行情摘要栏或页脚）固定一行"仅供研究参考，不构成投资建议"；完整方法与免责声明放默认折叠的 `<details>`，不进首屏；证据区不进入产物。

## 阅读预算

- 可见正文目标700—1100阅读单位，硬上限1500（约3—4分钟）。桌面端是2000—2800，移动端必须更狠地删。
- 删除顺序：宏观次要项 → 板块过程 → 个股背景；日期、买入条件、失效条件、风险永不删。

## 文案风格（小红书语感）

- 标题党克制版：允许口语化和情绪化词汇（"缩量""扛住""别追"），禁止夸张承诺；不用"荐股""带买""牛股"类词。
- 每句不超过40个中文字符；多用短句和换行，少用长段落。
- emoji只用于栏目小标题和数据强调（每只股最多1个），全文不超过15个；桌面端禁用emoji的规则不适用于移动端，但也不得滥用。
- 禁用词与桌面端相同："必涨、稳赚、抄底、必中、最佳买点、保证收益、明日一定"。
- 必须保留免责声明，措辞可精简但含义不变。

## 小红书笔记文案

单独输出 `.md` 文件，结构：

```markdown
# 标题（≤20字，含日期和最强结论，可带1个emoji）

正文（≤800字）：
- 第1段：今天市场一句话结论+宜/忌
- 第2段：重点板块（最多2个，各2行）
- 第3段：核心选股（每只3行：逻辑/建议/失效条件；失效条件用形态描述，不写精确价位）
- 第4段：风险提示（最多3条）
- 末段：免责声明一行

#A股 #股市 #财经 （3—6个话题标签，按内容补充）
```

- 正文不写证据编号 `[E01]`；把"证据"转成"数据显示/公告称"等自然语言。
- 不承诺收益，不含外链，不含导流话术（小红书社区规范）。
- 话题标签用中性研究词（#A股 #财经 #股票复盘 等），避开"荐股/带买/牛股"类标签；详见 `xhs-preflight.md`。
- 配套图片建议：把移动端HTML按栏目截屏为3—5张竖图，封面用cover区。

## 移动端校验

生成后运行：

```bash
python <skill-dir>/scripts/validate_report.py <report.html> --format mobile
```

移动端校验差异：检查移动端视觉令牌与 `m-shell` 骨架、可见单位上限1500、emoji计数≤15；其余（必需id、栏目顺序、静态安全、禁用词、details折叠）与桌面端一致。
