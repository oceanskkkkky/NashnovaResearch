# 桌面端 A 股选股日报规范

## 阅读预算

将展开前正文控制在10分钟内：

- 可见正文目标：2000—2800阅读单位；硬上限3200。
- 阅读单位：每个中文字符计1，每个英文单词或数字串计1。
- 按每分钟320阅读单位估算。
- 完整评分、方法和数据缺口说明放入默认折叠的 `<details>`，不计入首轮正文。
- 证据台账（编号、来源、口径、降级）只在分析过程中维护，存入同目录旁车文件 `YYYY-MM-DD-evidence.md`；产物HTML不出现证据区和 `[E01]` 等编号，正文改用"数据显示/公告称/龙虎榜显示"等自然语言归因。
- 删除重复背景、市场常识和无行动意义的宏观描述；每个结论必须回答“这对选股或操作意味着什么”。

栏目预算：

| 栏目 | 可见内容目标 |
|---|---:|
| 标题与行情摘要 | 300 |
| 宏观大势 | 400 |
| 大盘与板块 | 600 |
| 核心选股 | 950 |
| 个性化建议 | 650 |
| 风险提醒 | 200 |

核心选股每只最多6个短要点；个性化股票每只最多5个短要点。超过预算时先压缩背景、公式、重复行情和候选池过程，不删除日期、风险、买入条件和失效条件。

## 文件与桌面布局

以 `../assets/report-shell.html` 为结构起点，并遵循 `visual-style.md` 的设计令牌与组件样式。生成完整单文件HTML：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>A股选股日报｜YYYY-MM-DD</title>
  <style>/* 内联样式 */</style>
</head>
<body>...</body>
</html>
```

要求：

- 面向桌面浏览器设计，主内容固定在 `1120px—1240px` 宽度，最小宽度不低于 `980px`。
- 使用横向表格、双栏研报布局和稳定列宽；不设计移动端卡片流，不写 `@media (max-width:...)` 响应式重排。
- 允许 `@media print`；禁止外部CSS、JavaScript、字体、图片和CDN。
- 对用户输入和外部文本进行HTML转义。
- 保存到 `reports/stock-almanac/YYYY-MM-DD-stock-almanac.html` 或用户指定路径。

## 视觉风格

采用常规券商晨报/投研终端风格：

- 页面背景：`#F4F6F8`
- 内容背景：`#FFFFFF`
- 主文字：`#1F2933`
- 次级文字：`#667085`
- 边框：`#D9DEE5`
- 强调色：`#A61B1B`
- 上涨：红 `#C62828`
- 下跌：绿 `#16825D`

只在页首标题栏使用“股市老黄历”字样、细朱红边框和一行“今日宜 / 今日忌”。正文标题使用“大盘判断、重点板块、核心选股、关注股建议、风险提示”等常规金融语言。

禁止：大面积米黄仿古背景、印章堆叠、生肖、五行、农历吉时、装饰性竖排文字、渐变、动画和过度阴影。

## 必需栏目与ID

1. `<header id="cover">`：标题、日期、数据截止日、简短宜/忌。
2. `<section id="executive-summary">`：行情摘要（id 保持 `executive-summary` 不变，显示标题固定为"行情摘要"）。
3. `<section id="macro">`：宏观大势，必须位于大盘判断之前。
4. `<section id="market">`：大盘判断。
5. `<section id="sectors">`：重点板块。
6. `<section id="picks">`：核心选股。
7. `<section id="watchlist">`：关注股建议，仅在用户提供关注股时生成。
8. `<section id="risks">`：风险提示。
9. `<details id="methodology">`：方法和免责声明，默认折叠。

产物中禁止出现 `<details id="evidence">` 或任何证据区；证据台账写入旁车文件。

不得给 `<details>` 添加 `open` 属性。

## 栏目内容

### 1. 标题栏

只保留：

- “股市老黄历 · A股选股日报”；
- 报告日期、评分交易日、盘前/盘后/休市版；
- 今日宜1条、今日忌1条；
- 一句说明：“老黄历仅为标题包装，正文为数据研究”。

不放大段市场判断，不做仿古装饰。

### 2. 行情摘要

首屏直接回答：

- 市场状态：进攻 / 中性 / 防守；
- 风险暴露建议：提高 / 维持 / 降低；
- 重点板块：最多2个；
- 首选股票：最多3只；
- 最大风险：1—2项；若任一入选板块触发严重拥挤或拥挤加速，必须占用其中1项。

使用一张横向摘要表或四个紧凑指标块。每项一两句话，不复述后文。

### 3. 宏观大势

作为独立板块放在“大盘判断”上方。展示：

- 国内增长、货币、信用与资金成本的当前方向；
- 美元、美债、VIX、海外股市或关键商品中最重要的2—3项；
- 最近72小时最多3条重点新闻跟进。

每条新闻使用四列：事件、A股传导、受益/承压方向、下一跟踪点，并注明发布日期。只选会改变风险偏好、行业盈利或资金成本的新闻；无明确A股传导的不展示。宏观板块结尾用一句话给出资产配置含义，不重复大盘技术判断。

### 4. 大盘判断

展示最有决策价值的数据：

- 三大指数趋势；
- 成交额相对20日均值；
- 上涨占比、涨跌停或新高新低；
- 估值与两融状态。

最后输出不超过3条“对选股的含义”，例如“缩量反弹，优先回调确认而非追涨”。宏观和外围内容不得在此重复展开。

### 5. 重点板块

每个板块最多显示：

- 热度分、价格动量 `P` 与正交资金残差分位 `R`；
- 是否出现量价背离或资金边际退潮；
- 拥挤度 `C`、5日变化 `ΔC5` 与最高20分拥挤扣分；
- 1个盈利或事件催化；
- 1个主要风险；
- 可执行结论：继续跟踪 / 等回调 / 暂不追。

不要展示长篇新闻摘要或完整研报观点。

### 6. 核心选股

默认输出1—3只，最多4只。优先用横向表格快速比较，再为每只股票补一张简洁建议卡。

比较表至少含：股票、所属方向、最终分、置信度、评分日收盘价、当前建议、核心风险。

建议卡必须包含：

- 一句话投资逻辑；
- 关键事实最多3条；
- 当前建议；
- 买入观察区间和收盘/量能确认；
- 持有者的止盈或减仓条件；
- 逻辑失效或风险止损条件；
- 催化、风险和置信度。

没有达标股票时说明零推荐原因，不创建空卡片。

### 7. 关注股建议

仅在用户提供关注股时生成。使用桌面横向表格，一股一行，字段为：

- 当前状态；
- 是否进入推荐榜及原因；
- 未持有建议；
- 已持有建议；
- 买入观察区间；
- 减仓/止盈触发；
- 逻辑失效位；
- 主要风险。

用户未提供成本时，不计算盈亏或仓位。被硬过滤的股票标记“风险观察，不进入推荐榜”。

### 8. 风险提示

最多5条，只保留下一交易日前后可能改变结论的风险：宏观、财报、解禁、减持、停复牌、监管、商品价格和关键数据缺口。

### 9. 方法、免责声明与证据台账

产物的方法区仅保留总公式、硬过滤、数据延迟、关键数据缺口与降级披露和免责声明，不在正文展示完整计算过程。

证据台账不进入产物：记录ID、来源、查询、时间、口径、覆盖、降级和Evidence路径/研报ID，保存到同目录 `YYYY-MM-DD-evidence.md`。隐藏Token和会话信息。

## 文案要求

- 先说结论，再说证据，最后说触发条件。
- 每段不超过90个中文字符；长内容改成表格或短要点。
- 避免“值得关注、持续看好、景气向上”等空话；必须补充数据、日期或触发条件。
- 区分“公司公告确认”“研报判断”“市场映射”。
- 允许给条件式买入、持有、减仓或回避建议，但不得使用“必涨、稳赚、抄底、必中、最佳买点、保证收益、明日一定”和未经校准的概率。
- 使用中国市场颜色习惯：涨红跌绿，并同时显示正负号和文字。

## 证据编号

分析过程中为关键事实分配 `[E01]` 等编号，每个板块和股票至少引用两个独立维度，编号唯一并可追溯到旁车证据文件。最终产物正文不出现证据编号，统一改写为"数据显示/公告称/龙虎榜显示"等自然语言归因。
