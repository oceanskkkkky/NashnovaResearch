# A股评分、过滤与交易建议

## 统一原则

将叶子指标归一化到0—100。横截面指标使用候选池百分位，时序指标使用同股票历史分位；负向指标反向计分。分数只做排序，不替代投资逻辑。最终分保留1位小数，正文不展示无用的小数和完整计算过程。

## 市场环境

```text
MarketEnvironment =
  30% × 指数与风格趋势
+ 25% × 市场宽度和情绪
+ 20% × 成交与流动性
+ 15% × 国内宏观流动性
+ 10% × 全球风险
```

检查：

- 指数与风格：上证、深证、创业板的MA20/60、5日/20日收益、大小盘和成长价值相对强弱。
- 市场宽度：上涨占比、涨跌停、新高新低；数据不完整时不生成虚假的情绪精确分。
- 成交：两市成交额相对20日均值。放量下跌时该项最高55分。
- 国内流动性：M1/M2、社融、资金成本、两融和股债风险溢价。
- 全球风险：VIX、美元、美债利率、海外指数和对A股有明确传导的事件。

映射市场状态：

| 分数 | 状态 | 选股约束 |
|---|---|---|
| `>=65` | 进攻 | 可从主线中选择趋势与基本面共振标的 |
| `45—64.9` | 中性 | 提高确认要求，优先回调与业绩确定性 |
| `<45` | 防守 | 提高门槛、减少标的；低于30可零推荐 |

## 板块热度

把原来的“价格30% + 资金25%”改成**35%量价正交趋势因子**，并对拥挤度单独扣分。这样既保留趋势识别能力，又避免价格上涨与资金流入对同一趋势重复计分。

```text
CoreHeat =
  35% × 趋势确认 T（价格动量 + 正交资金残差）
+ 15% × 成份股广度
+ 10% × 市场关注度
+ 10% × 新闻与政策催化
+ 10% × 盈利预期、研报与估值

Opportunity = CoreHeat / 0.8（CoreHeat满分80，归一化回0—100）
SectorHeat = Opportunity - CrowdPenalty
CrowdPenalty ∈ [0, 20]
```

V3起拥挤度**只扣分、不加分**：低拥挤不等于机会，`C<=50` 时 `CrowdPenalty=0`（中性不奖不罚），只有中高拥挤才开始扣分。最终 `SectorHeat` 仍为0—100分，继续使用65分门槛。

### 趋势确认（35%，量价正交化）

价格与资金在趋势市中高度共线。不要直接把二者线性相加；使用全板块横截面回归剔除“由价格涨跌自然解释的资金变化”，只保留资金的独立增量信息。

1. 在完整板块池中，把每个周期的收益和资金净流入强度转成当日横截面百分位分数（0—100）；板块池不少于20个，数据覆盖率不少于80%。
2. 按下式合成多周期分数，降低单日脉冲权重：

```text
P = 20%×P1 + 35%×P5 + 45%×P20
F = 20%×F1 + 35%×F5 + 45%×F20
```

3. 对横截面 `P`、`F` 做1%/99%缩尾并标准化为 `zP`、`zF`，每日拟合：

```text
zF = α + β×zP + ε
```

4. 将资金残差 `ε` 在当日全板块中重新映射为百分位 `R`（0—100）。`R=50` 表示资金强度与价格表现大致匹配；`R>50` 表示有超出价格表现可解释范围的独立资金流入；`R<50` 表示资金弱于价格表现。
5. 合成趋势确认：

```text
T = 70%×P + 30%×R
```

价格作为趋势锚占70%，正交后的资金残差占30%。资金只奖励“超预期流入”，不再重复奖励已经反映在价格中的趋势。

量价预警与硬上限：

- `P >= 70 且 R <= 20`：价格强、正交资金弱，标注“量价背离：上涨缺少增量资金确认”，且 `SectorHeat` 上限60；
- `P >= 70 且 R 连续5日下降 >=20分位点`：标注“趋势仍强但资金边际退潮”；
- `P <= 50 且 R >= 80`：标注“资金先行潜伏”，只进入观察池，等待价格确认，且 `SectorHeat` 上限60；
- 回归样本不足20个、覆盖率不足80%或回归方差近零时，降级为 `T = 65%×P + 35%×min(P,F)`，标注“正交化降级”，并将板块置信度降低一档；
- 资金数据缺失时使用 `T = min(P,50)`，不得把缺失资金解释为中性确认。

绝对方向约束（防止相对分位在弱市中产生虚假高分）：

- 板块5日与20日原始收益均 `<=0`：`T` 上限55，标注“5日与20日绝对收益均为负”；
- 板块5日与20日资金强度（净流入/成交额）均 `<=0`：`R` 上限50，标注“资金绝对流向为负”；
- 每日回归必须记录 `α/β/R²`；`R²<0.2` 时标注“正交解释力弱”，残差分仅作参考。

### 拥挤度惩罚（最高20分，提前预警项）

三项均取**板块自身近一年历史分位**（0—100，时序分位而非当日横截面）：

| 子指标 | 权重 | 数据口径 |
|---|---:|---|
| `RSI_pct` | 35% | 板块指数 RSI(14) 当前值在近一年中的分位 |
| `Turnover_pct` | 35% | 板块近5日均换手率在近一年中的分位 |
| `Share_pct` | 30% | 板块近5日成交额占全市场比重在近一年中的分位 |

为避免均值掩盖某个极端指标，引入尾部增强：

```text
M = 35%×RSI_pct + 35%×Turnover_pct + 30%×Share_pct
C = 75%×M + 25%×max(RSI_pct, Turnover_pct, Share_pct)
ΔC5 = C(今日) - C(5个交易日前)

LevelPenalty =
  0分，C <= 50（低拥挤不加分，中性不奖不罚）
  20×(C-50)/50，C > 50（中高拥挤线性扣分，C=100时扣满20）

AccelerationPenalty =
  0分，ΔC5 < 5
  1分，5 <= ΔC5 < 10
  2.5分，10 <= ΔC5 < 20
  4分，ΔC5 >= 20

CrowdPenalty = min(20, LevelPenalty + AccelerationPenalty)
```

预警规则与总分并行触发，不因板块未入选而省略：

- `C >= 90` 或 `CrowdPenalty >= 18`：**严重拥挤**。默认不作为主推荐；仅当 `SectorHeat >=70` 且 `R >=50` 时可保留1个，并在行情摘要与板块卡片标注“严重拥挤，追高风险”，对应个股 `RiskPenalty +5`；
- `80 <= C < 90`：**高拥挤**，标注“仅观察回调，不追高”；
- `70 <= C < 80`：**拥挤升温**，标注“注意波动放大”；
- `ΔC5 >= 10`：无论当前水平高低，额外标注“拥挤加速”；
- 任一子指标 `>=95`：额外标注具体极端项，例如“换手率近一年极端分位”；
- 缺失1项时用其余两项计算并降低置信度；缺失2项及以上时以 `C=50` 降级，不计算加速度，不得声称“低拥挤”，并将置信度降低一档。

板块入选条件：

- `SectorHeat >= 65`；
- 证据独立性：趋势确认、广度、关注度归为“交易证据”，新闻政策、盈利预期、研报与估值归为“非交易证据”；主推荐至少需要1项交易证据 + 1项非交易证据；缺失按50分处理的项目不计入证据数量，只有交易证据的板块只进观察池；
- 5日或20日维度不能与单日结论完全相反而未解释；
- 存在流动性合格、可深度核验的A股候选；
- 严重拥挤板块必须满足上面的额外约束；未达约束时只进入风险观察，不进入主推荐。

## 个股评分

```text
StockScore =
  25% × 基本面质量与盈利趋势
+ 25% × 技术趋势与位置
+ 20% × 资金结构
+ 15% × 相对板块和指数强度
+ 10% × 催化与预期差
+ 5% × 流动性和可交易性
```

### 基本面质量与盈利趋势

- 收入、净利润与扣非利润趋势：30%。
- ROE、毛利率、净利率与经营现金流质量：30%。
- 资产负债、应收、存货和商誉风险：20%。
- 一致预期变化、估值与增长匹配：20%。

单一高增长但现金流、负债或一次性损益恶化时不得高分。周期股用行业位置和盈利周期解释，不机械套用静态PE。

### 技术趋势与位置

- MA20/60结构及斜率：35%。
- MACD趋势：20%。
- RSI/KDJ与过热风险：15%。
- BOLL和20/60日位置：15%。
- 量价配合及近期高低点：15%。

极端超买不自动加分；上涨远离MA20时降低“可执行性”分。

### 资金结构

```text
资金结构 =
  60% × 主力资金1/5/20日趋势
+ 20% × 龙虎榜机构席位
+ 10% × 两融变化
+ 10% × 北向季度持仓变化
```

大宗交易只作解释或风险，不自动计正分。不同口径分别展示，不合并成“机构资金”。

### 催化与预期差

只计可验证且可能影响盈利或估值的事项：业绩超预期、订单、产品量产、价格变化、资本开支、政策、回购等。相同事件转载只计一次；纯概念映射不给高分。

## 最终分

```text
FinalScore =
  15% × MarketEnvironment
+ 25% × SectorHeat
+ 60% × StockScore
- RiskPenalty
```

股票不属于重点板块但自身基本面和催化显著时，可使用中性 `SectorHeat=50`，并在报告中标记“个股独立逻辑”，不得虚构所属热点。

## 评分透明度

生成每期报告时保留评分拆解表，不得只展示无法复核的总分：

- 板块记录 `P1/P5/P20`、`F1/F5/F20`、合成后的 `P/F`、回归 `α/β/R²`、正交资金残差及百分位 `R`、趋势确认 `T`、绝对方向约束与分数硬上限触发记录、拥挤度三项分位、`M/C/ΔC5`、水平扣分、加速度扣分、广度、关注度、催化、研报/盈利/估值、`CoreHeat`、`Opportunity`、最终 `SectorHeat` 和板块置信度。
- 个股记录基本面、技术、资金、相对强度、催化、流动性六项原始分、权重、加权贡献、风险扣分和最终 `FinalScore`。
- 每项分数必须能追溯到原始字段、数据日期和证据编号；缺失项明确标为中性50分或不适用。
- 正文只展示关键分项，完整拆解放入证据或方法折叠区。
- 未保存分项台账时，不得声称某个带小数的总分是精确计算结果；只能写“高/中/低”或区间判断。

## 风险扣分

最高扣30分：

| 风险 | 扣分 |
|---|---:|
| 重大监管、诉讼、债务、审计或退市风险 | 10—20 |
| 高比例解禁、质押、大股东或高管减持 | 每项5，最多15 |
| 近20日波动率处候选池前10% | 5 |
| 连续涨停、成交不可得或显著偏离MA20 | 5—10 |
| 估值处历史极高分位且盈利预期未上修 | 5 |
| 核心证据冲突或产业关系未验证 | 5—10 |

## 硬过滤

出现任一项则不进入推荐榜：

- ST、`*ST`、退市整理或明确重大退市风险；
- 评分日停牌或已知下一交易日停牌；
- 上市不足20个交易日；
- 最近20日成交额中位数低于1亿元；
- 缺少有效收盘价、核心技术或关键基本面数据；
- 代码无法唯一确认；
- 重大未决风险无法合理评估；
- 仅靠未经公司披露的概念映射，没有价格、资金或基本面第二证据。

用户关注股触发过滤时仍进入个性化风险观察，但必须标记“不进入推荐榜”。

## 数据置信度

```text
Confidence = 时点合格且有效的评分权重 / 理论总权重 × 100%
```

- `>=90%`：A
- `75%—89%`：B
- `60%—74%`：C
- `<60%`：不入榜

不适用项不扣置信度；可用但缺失的叶子项按50分且降低置信度；过期数据视为缺失。

## 入榜门槛

- 常规：`FinalScore >= 65` 且 `Confidence >= 75%`。
- 市场中性：优先选择 `FinalScore >= 68`，默认最多3只，上限5只。
- `MarketEnvironment <45`：门槛提高到70，最多2只。
- `MarketEnvironment <30`：零推荐，只给风险提示。
- 同一板块最多2只。
- 保守型：门槛再加5分且置信度至少85%。
- 激进型：不得放宽硬过滤、证据和失效条件。

## 条件式交易建议

### 未持有

| 状态 | 建议 |
|---|---|
| 分数高、趋势确认、未过热 | 条件式参与：给买入观察区间、收盘与量能确认 |
| 分数高但明显偏离MA20或超买 | 逢回调观察：不追价，等待支撑区企稳 |
| 逻辑成立但趋势/资金未确认 | 等待：给出转强触发条件 |
| 分数或置信度不足、风险较高 | 回避：给出重新评估条件 |

### 已持有且提供成本

- 趋势、资金和逻辑仍成立：持有观察，给保护位和止盈触发。
- 接近重要阻力且超买、资金背离：分批止盈观察。
- 跌破关键支撑且逻辑弱化：减仓防守。
- 出现重大风险或硬过滤：风险退出观察，不等待技术反弹确认。

### 价格条件

- 买入观察区间：由MA20、BOLL中轨/下轨、近期平台或成交密集区构成。
- 确认条件：优先“收盘站稳关键位 + 成交量不低于20日均量”。
- 止盈/减仓触发：前高、布林上轨、超买与资金背离共同判断。
- 逻辑失效位：关键支撑或MA20/60，需说明为什么该位置代表逻辑被破坏。
- 避免给单一精确价；优先给区间和条件。所有价位使用评分日数据并标明日期。
