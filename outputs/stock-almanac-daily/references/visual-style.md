# 交易老黄历前端视觉规范

本规范改编自用户提供的 `trading-almanac-ui` 视觉系统。保留其纸墨质感、深墨绿结构、朱砂与金色细节、宋体标题和直角卡片；删除浏览器端JavaScript、页签切换和移动端重排，适配静态桌面A股研报。

## 设计令牌

```css
:root{
  --paper:#f3efe6;
  --paper-deep:#e8e0d0;
  --ink:#18332d;
  --body:#26332f;
  --jade:#17705e;
  --red:#a83e32;
  --gold:#b98532;
  --line:rgba(24,51,45,.22);
  --muted:#69736d;
  --card:rgba(255,253,247,.78);
  --serif:STSong,"Songti SC",SimSun,serif;
  --sans:-apple-system,BlinkMacSystemFont,"PingFang SC","Microsoft YaHei",sans-serif;
}
```

遵循中国A股色彩约定：上涨使用朱砂红，下降使用玉绿。所有涨跌同时显示正负号和“涨/跌”文字，不仅依赖颜色。

## 页面骨架

- `body` 最小宽度1268px，页面允许窄屏横向滚动，不做移动端重排。
- 深墨绿全宽页头；内部内容宽1220px并居中。
- 主体宽1220px，顶部42px、底部32px。
- 顶部页头包含：35px方形“历”字印章、产品名、英文副标题、纯锚点章节导航、数据状态。
- 页头下使用Hero：左侧为数据日期、市场结论、宜/忌；右侧为深墨绿摘要面板。
- 正文以同页章节顺序展示：宏观大势、大盘判断、重点板块、核心选股、关注股建议、风险提示。
- 不使用交互页签、隐藏屏幕或点击后才显示的内容。

## 卡片与排版

- 卡片使用接近直角的细边框，不使用大圆角。
- 基础卡片：`background:var(--card); border:1px solid var(--line); box-shadow:3px 4px 0 rgba(24,51,45,.035); padding:22px`。
- 一级标题使用宋体24px；页首主标题固定48px；正文使用系统无衬线14px、1.65行高。
- 使用金色11px大写kicker标记章节，例如 `01 / MACRO PULSE`。
- 数字启用 `font-variant-numeric:tabular-nums`。
- 主要内容采用1.55fr/0.7fr双栏或语义化横向表格；股票建议使用“主表 + 静态详情卡”。
- 深墨绿面板仅用于首屏结论、策略或风险摘要，不大面积铺满正文。

## 模块表现

### 宏观大势

使用浅色卡片，分为“增长与流动性”“全球风险”“重点新闻跟进”。新闻采用横向表格，列为事件、A股传导、受益/承压方向、后续跟踪点。每条显示日期与证据编号。

### 大盘判断

三大指数使用三列数字格；下方用双栏展示市场宽度与资金/风格。成交、涨跌家数和估值使用紧凑指标格，不把宏观新闻重复写入。

### 重点板块

使用排序列表：金色序号、板块名称、核心逻辑、资金与趋势、右侧热度分。补充一行主要风险和操作结论。

### 核心选股

先展示静态比较表，再展示每只股票详情卡。详情卡必须包含投资逻辑、关键证据、当前建议、买入观察、止盈/减仓、失效条件和风险。

### 关注股建议

使用真正的HTML表格，不使用按钮或动态雷达。所有关注股结论一次性可见。

## 禁止项

- 禁止 `<script>`、外部CSS、远程字体、图片、CDN和接口请求。
- 禁止从参考模板复制页签JS、`.screen{display:none}` 或 `@media(max-width:...)`。
- 禁止玻璃拟态、大圆角、强渐变、闪烁、动画和表情符号。
- 禁止仿古元素淹没信息；“历”印章、纸纹、金色编号即为全部主题包装。
- 禁止把参考模板中“绿涨红跌”直接照搬；本Skill固定红涨绿跌。

## 可访问性与安全

- 用户文本、新闻和研报内容在写入HTML前转义。
- 空值显示 `--` 并说明“数据待补”，不造数。
- 证据、数据时间和覆盖状态可见；详细证据放默认折叠区。
- 使用语义化 `header`、`nav`、`main`、`section`、`table`、`details`。
